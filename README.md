Calculadora 3D

Uma calculadora tridimensional para realizar cálculos e visualizar resultados em um ambiente 3D.

🚀 Funcionalidades
Operações matemáticas básicas: adição, subtração, multiplicação e divisão.
Visualização dos cálculos em um ambiente 3D.
Interface interativa e intuitiva.
Atualização dos resultados em tempo real.
Suporte a diferentes valores e expressões matemáticas.
🛠️ Tecnologias
HTML
CSS
Java Script

📦 Como executar

Clone o repositório:

git clone https:[//github.com/seu-usuario/calculadora-3d.git](https://github.com/PhenriqueeS/Calculadora-3D)


Entre na pasta do projeto:

cd calculadora-3d


Abra o arquivo index.html no navegador ou utilize um servidor local.

🎮 Como usar
Digite os valores desejados.
Escolha a operação matemática.
Visualize o resultado na interface 3D.
Utilize os controles disponíveis para interagir com a visualização.
